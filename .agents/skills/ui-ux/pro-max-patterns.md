# SKILL: UI/UX PRO MAX (Premium Layer)

## PURPOSE
To elevate the base Stitch designs with premium aesthetics, motion, and responsiveness, creating a "world-class" first impression.

## WHEN TO USE
- Polishing UI components
- Implementing interactions (hover, click, transitions)
- Designing high-conversion landing pages

## INPUT
- Base Stitch Component
- Aesthetic Target: "Liquid Solar Glass"

## OUTPUT
- Premium, animated UI interface

## EXECUTION STEPS
1. **Apply Glassmorphism**: For dashboard cards, use blurred backdrops and subtle borders to create depth.
2. **Implement Premium Motion**: Add smooth CSS transitions and Framer Motion animations for page entries and status changes.
3. **Use HSL Tailored Colors**: Avoid generic colors; use curated, vibrant palettes that feel modern and energetic.
4. **Enhance Micro-interactions**: Add subtle scaling, shadow shifts, or color glows to interactive elements (buttons, nav items).
5. **Enforce Responsiveness**: Ensure "Liquid" layouts that adapt beautifully across Mobile, Tablet, and Desktop resolutions.

## VALIDATION RULES
- Interaction latency < 100ms.
- Smooth transitions on ALL navigation events.

## FAILURE CONDITIONS
- Static, "flat" UI that lacks depth or motion.
- Basic default browser styling for buttons or forms.

- `.agents/skills/ui-ux/stitch-integration.md`
